Private, ad-free file sharing between nearby devices — no accounts, no cloud, no internet. This release brings CrossDrop to Linux.

## What's new

- **CrossDrop for Linux** — a desktop app for Ubuntu, Debian, Fedora, openSUSE and other x86-64 distributions, with the same live radar, "Send to anyone" QR sharing and Wireless Drive as the Mac and Windows apps. Phones, Macs, PCs and Linux machines on the same Wi-Fi all see each other. Received files go to a **`CrossDrop` folder inside your Downloads**. Pick the `.deb`, the `.rpm`, or the portable `.tar.gz` below.
- **Good to know** — the Linux packages are not signed yet, and there is no apt or dnf repository, so updates mean installing the new package. Closing the window keeps CrossDrop running in the system tray; on GNOME that needs the AppIndicator extension (Ubuntu has it), otherwise closing the window quits it.
- **Everything else** — the Android, Windows, Mac, iPhone and iPad apps have no user-visible changes in this release; their version number moves with it.

Everything still travels straight between your devices over Wi-Fi, end-to-end encrypted. No new permissions are needed — see the [privacy policy](https://github.com/GranTurismo/crossdrop/blob/main/PRIVACY.md).
