Private, ad-free file sharing between nearby devices — no accounts, no cloud, no internet. This release makes it easy to connect two devices that aren't on the same Wi-Fi.

## What's new

- **CrossDrop Wi-Fi** — not on the same Wi-Fi? On an Android phone, tap Connect directly, then **Make a CrossDrop Wi-Fi**. The phone makes a network called `DIRECT-CD-CrossDrop` and shows its name and password in large type straight away. On most phones it keeps its own Wi-Fi meanwhile.
- **Join it in one tap** — on the other phone, iPhone or iPad, tap **Join a CrossDrop Wi-Fi** and confirm: no code to scan. A laptop without CrossDrop picks the network in its Wi-Fi list and types the short password `crossdrop123`.
- **Mac, Windows and Linux join with one click** — the desktop app's "Join a CrossDrop Wi-Fi" joins through the system, and forgets the network again when you leave, so your computer never joins it on its own later.
- **A simpler choice** — "Show a code / Scan a code" is now "Make a CrossDrop Wi-Fi / Join a CrossDrop Wi-Fi". Scanning a code still works (for older versions, or a phone that can only make a network of its own naming).
- **About the password** — it is the same on every phone, so it only keeps the network from being open. What you send stays end-to-end encrypted, the other device still accepts each offer, and the network switches itself off after 30 minutes at most.
- **Everything else** — the new screens are translated into all ten languages. Every app moves to 0.13.0 (the iPhone, iPad and Mac App Store app to 1.7.0).

Everything still travels straight between your devices, end-to-end encrypted. See the [privacy policy](https://github.com/GranTurismo/crossdrop/blob/main/PRIVACY.md).
