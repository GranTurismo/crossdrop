Private, ad-free file sharing between nearby devices — no accounts, no cloud, no internet. This release puts what you receive where you expect it, and makes shared drives feel live.

## What's new

- **Received files go to Downloads** — on Android, Mac and Windows, files you accept now land in a **`CrossDrop` folder inside Downloads**, so you can open them from your file manager or any other app. Files already in your inbox are moved there automatically the first time you open the new version. On Android this needs no new permission; on a Mac, macOS asks once to allow access to Downloads. iPhone and iPad keep received files in the Files app under CrossDrop, because iOS does not let an app write to the shared Downloads folder.
- **Shared drives update live** — when a device shares a drive, a file added to it shows up on the other device within a couple of seconds, without pulling to refresh. The same goes for files removed, renamed or uploaded by someone else, and for the page opened in a browser. It is checked only while the app is on screen.
- **Good to know** — on Android, sending the same file again now saves a numbered copy (`file (1).pdf`) instead of updating the earlier one. **Wipe all** in the inbox overwrites and deletes everything in that Downloads folder, including files you put there yourself.

Everything still travels straight between your devices over Wi-Fi, end-to-end encrypted. No new permissions are needed — see the [privacy policy](https://github.com/GranTurismo/crossdrop/blob/main/PRIVACY.md).
